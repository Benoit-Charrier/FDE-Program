# Solivian RSI Version History

This file is for context regarding RSI evolution. The system you design should always evaluate expectedness against the **current** RSI version at the time of AE assessment.

| Version | Effective date | Material changes from prior |
|---|---|---|
| v1 | 2021-11-12 (initial FDA approval) | Initial RSI |
| v2 | 2022-08-03 | Added heart failure exacerbation (uncommon) following first-year postmarketing data |
| v3 | 2023-12-08 | Added boxed warning for drug-induced liver injury with hepatocellular pattern (rare). Added embryo-foetal toxicity boxed warning. |
| **v4** | **2024-11-19 (current)** | Added AKI (rare). Refined HF exacerbation language. Added hepatic injury (transaminases >3× ULN with bilirubin elevation) as uncommon-expected. |

NOTE: The current RSI (v4) lists Grade 3 transaminase elevation WITH bilirubin elevation as uncommon-expected. For AE-2026-05-09-001 (J.D. Tezarimab patient), the relevant RSI is the **Tezarimab** RSI v3 — not Solivian. See `Tezarimab_RSI.md`.
